---
description: Registra um repositório no hub
argument-hint: "[argumentos]"
---

Argumentos: $ARGUMENTS

Rode `hubspec hub add <url>` com as opções dadas (`--description`, `--tags`, `--depends`). Para um repo que a automação da organização acabou de criar para uma change, use `--new --change <change>`: ele clona o repo, vincula à change e conclui a task manual.

Depois, sugira documentar o repo novo com `hubspec hub document <repo>`.
